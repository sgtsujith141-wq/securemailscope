# Frontend

**STATUS: NOT IMPLEMENTED.** Planned for M8.

This directory is a placeholder. There is no React application, no build
configuration and no `package.json` yet.

Building a dashboard before there is anything true to put on it would produce
exactly the "dummy dashboard with fake statistics" this project is meant to
avoid. The UI will be built once the assessment layer (M4) produces findings
worth displaying, and it will render only what the engine actually observed —
including, prominently, what it could *not* determine.
