## The narration is synthesised

The voice is generated by **ElevenLabs** (`eleven_multilingual_v2`, voice
*Neel*). **It is not a person.** That is stated here, in `narration.md`, in
`video-description.md` and in `submission/README.md`. The script, the voice id
and the exact settings are committed in `local-evidence/narration/script.json`
and `scripts/make_narration.sh`, so a rebuild sounds the same.

The operating system's own speech synthesis was used in an earlier cut and
rejected: it sounded robotic. The audio in this cut is neural, paced at about
141 words per minute, and mixed so the voice stays dominant.

## Data provenance

Every capture is synthetic and generated by the project's own fixture
generators (`scripts/build_demo_dataset.py`). The analyzer has no demo mode
and does not recognise these filenames; `demo/manifest.json` records what each
one demonstrates alongside what the engine actually observed.

## Reproducing it

```bash
python scripts/build_demo_dataset.py
cd frontend && SMS_SCREENSHOTS=1 npx playwright test demo-capture && cd ..
bash scripts/make_narration.sh          # needs an authenticated ElevenLabs CLI
.venv-release/bin/python scripts/build_demo_video.py
```

Without the narration step the same cut still builds, and every line is
carried by an on-screen caption.
