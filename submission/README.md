## Rebuilding

```bash
python scripts/build_demo_dataset.py            # the nine synthetic captures

cd frontend
SMS_SCREENSHOTS=1 npx playwright test submission-shots   # the screenshots
SMS_SCREENSHOTS=1 npx playwright test demo-capture       # the raw footage
cd ..

python scripts/render_report_page.py \
  local-evidence/submission-report.pdf \
  submission/assets/screenshots-final/12-pdf.png         # the PDF page image
.venv-release/bin/python scripts/build_demo_video.py     # the video
.venv-release/bin/python scripts/build_presentation.py   # the deck and PDF
python scripts/write_manifest.py                         # the hashes
```

The deck build **fails** rather than producing a deck with the wrong team name,
a seventh slide, or a missing identifier. It is not a formatting convenience.

## Status

Every title-page value is resolved: problem statement **SIH26159**,
organisation **NTRO**, theme **Blockchain & Cybersecurity**, category
**Software**, team ID **146876**, team name **Zero-Day**. The build refuses to
produce a deck containing an `[UNRESOLVED: ...]` marker, so the absence of one
is checked rather than assumed.

The **demonstration video is finished**: 2 min 59 s, 1920x1080, 30 fps,
H.264 High CRF 18, AAC 192 kbps at -16.0 LUFS, built from a Playwright
recording of the real application driving the real backend over the real
forensic engine, one recording per shot. It opens with the team introducing
itself over the title card and then shows the product doing the work: the same
finding, the same packets, the same score and the same drift example the deck
does.

Its narration is **synthesised** by a neural speech provider (ElevenLabs,
voice *Neel*) and is labelled as such in `demo/narration.md` and
`demo/demo-verification.md` — it is not a person. The script, the voice and
the exact settings are committed so a rebuild sounds the same; the audio
itself is regenerated by `scripts/make_narration.sh`.

## Data

Every capture, screenshot and frame of footage uses synthetic data generated by
the project's own fixture generators. Every hostname is a reserved `.invalid`
name (RFC 2606). No real mail traffic, from any person or organisation, appears
in any artifact here.
